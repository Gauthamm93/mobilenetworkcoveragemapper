# Mobile Network Coverage Mapper

An Android application that records mobile network signal strength and GPS locations, helping users visualize network coverage on a map.

## Features

- Record mobile network measurements with GPS coordinates.
- Display saved measurement locations on an OpenStreetMap-based map.
- View signal-strength values in dBm.
- Store measurements for later viewing.
- Visualize mobile network coverage using mapped measurement points.
- Browse previously recorded measurements.
- Use camera determine more network region

## Technologies Used

- **Language:** Kotlin
- **UI:** Jetpack Compose
- **Map:** OpenStreetMap
- **Platform:** Android
- **Location:** GPS and Android location services

## How It Works

1. Open the application on an Android device.
2. Allow the necessary location and phone-state permissions.
3. Record mobile network measurements.
4. Save the signal-strength values and associated GPS coordinates.
5. Open the coverage map to view the recorded locations.
6. Review measurement history to inspect previously collected data.

## Installation

1. Clone or download this repository.
2. Open the project in Android Studio.
3. Allow Gradle Sync to complete.
4. Connect an Android device or start an emulator.
5. Build and run the application.

## Future Enhancements

- Signal-strength heatmap visualization.
- Network operator and network-type filtering.
- Improved measurement history and map interaction.
- Coverage comparison across different locations.
- Export measurements for further analysis.

## Project Purpose

This project aims to help users understand mobile network coverage by collecting location-based signal measurements and displaying them geographically.
